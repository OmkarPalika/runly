# runly-go

[yaegi](https://github.com/traefik/yaegi) v0.16.1, the Go interpreter by
Traefik Labs, compiled to `wasip1/wasm`. runly loads `yaegi.wasm` from this
package to run Go snippets in the browser.

Build it with `npm run build` (requires Go 1.21+). The binary isn't committed.
