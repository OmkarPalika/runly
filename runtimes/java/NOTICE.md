# @browserrun/java

This package redistributes, unmodified, the prebuilt files of
[teavm-javac](https://github.com/konsoletyper/teavm-javac) by Alexey Andreev,
as published at https://teavm.org/playground/.

- teavm-javac and TeaVM are licensed under the Apache License 2.0 (see LICENSE).
- The compiler includes the Java compiler and class library definitions from
  OpenJDK, licensed under GPL-2.0 with the Classpath Exception. Their source is
  available from the OpenJDK project; the exact revision is pinned in
  teavm-javac's `gradle.properties` (`jdk.revision`).

Checksums of the redistributed files are in SHA256SUMS in the source repository.
