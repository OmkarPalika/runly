# runly-java

The [teavm-javac](https://github.com/konsoletyper/teavm-javac) compiler (OpenJDK
javac and TeaVM compiled to WebAssembly). runly loads it from this package to
compile and run Java in the browser.

`npm run fetch` downloads the files from teavm.org and verifies them against
SHA256SUMS. The binaries aren't committed. See NOTICE.md for licensing.
